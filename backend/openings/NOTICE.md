# Opening names

`openings.tsv` combines `a.tsv` … `e.tsv` from
[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings)
(commit 3ba6b20, 5 Nov 2026): ECO code, opening name and the moves that
reach it. That data is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

To update it, replace the file with the same files from a newer copy of that
repository (keep a single header line).
